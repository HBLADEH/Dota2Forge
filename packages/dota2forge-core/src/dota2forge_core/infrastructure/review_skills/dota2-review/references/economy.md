# 对线、发育与经济

只按series的semantic、unit和真实时间读取。STRATZ的networth_level是净资产，OpenDota的collected_gold是收集金；两者不直接比较。checkpoints只包含确有的采样点，5分钟缺失不能拿4分钟或终局数冒充。团队优势为天辉领先，夜魇目标需解释符号。

先描述一个有依据的区间：哪个时间采样到多少、随后变化多少。变化不证明正在某一路、漏了几波线或死亡导致停滞；这些需要位置、补刀或死亡事件。只有GPM时可谈整局收集金速率，不能重建每分钟的过程。

核心位讨论资源获取与关键装备所需能力；辅助位优先讨论等级/功能装/安全行动条件，不用核心补刀门槛评分。lane/位置未知时保留不确定性。没有同口径基准，不将绝对净资产低直接等同于发挥差。

把建议写成可选择的行动：安全兵线可收时怎样保持资源、无法安全站线时怎样与队友换区域、等待关键装时怎样降低无收益接战。明确这些是下局策略，不是本场已经发生的走位。涉及拉野、游走或支援时说明离线后谁能接住原有资源，以及失败代价。

给用户一个可检查的练习：在某个阶段记录离线目的与收益、关键装完成后计划的行动等。不要编造地图坐标、固定必达经济数字或无法核实的计时机制。需要说明走势时补经济图，但同时给行动建议。
