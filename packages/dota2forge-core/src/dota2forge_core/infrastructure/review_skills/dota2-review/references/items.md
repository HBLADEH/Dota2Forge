# 出装与购买顺序

使用purchases和lineup，不只看最终六格。赛前负时间、组件、图纸和重复消耗品都是原记录；购买不证明已合成、送达、仍在背包或成功使用。缺少物品映射时保留已知ID/key并说明，不能臆造中文装备。

先定义装备需要解决的问题：发育效率、进场和输出环境、先手、控制、生存、队友保护、清线或推进。根据目标英雄位置、双方英雄机制及已知购买时间确定本轮最相关的需求。若涉及精确驱散/BKB/伤害类型交互而本场版本依据不足，就给条件分支，避免错误的确定结论。

评价关键购买时问：这件装备增加什么行动能力？此时更缺哪种能力？先小件还是攒大件各有什么代价？至少给出一个具体调整候选及其适用条件，并解释何时应保留原路线。常见/高胜率不等于本局最优，不能只因为输局就否定路线。

引用真实时间进行比较，例如“来源在T记录了A；若当时主要威胁是X，可优先考虑解决X的B，代价是推迟Y”。未核实价格、对手装备、技能冷却或实际持有时，不计算一份精确但虚构的购买计划，也不声称某次死亡可被某件装备必然避免。

主动装建议附带使用时机和目标；功能品按已知隐身、行动需求决定，不机械分配给五号位。库存金、购买与使用是不同证据。用户问“顺序怎么改”时先用文字给替代路线和条件，再按需补时间线图，图不是答案本身。
