# 综合复盘

确认比赛时长、目标英雄、实际位置/阵营和本场版本。读取lineup看双方英雄；未知位置不猜分路，第三方英雄用“该英雄”。对手的单场装备如未返回，不能假设他们已经做出某件反制装。

先看availability。区分基础结算、目标经济、购买、团队优势和未接入事件；“已解析”不等于字段完整。source_attempts有记录时简短说明尝试原因与最终来源；没有可用时间线就不写具体分钟节点。

按本局实际长度划分阶段，不为短局生成不存在的后期。综合检查：

- 对线和资源：优先看精确5/10分钟采样，评价职责相关的资源与等级；缺少分钟补刀就不评当时补刀。
- 经济和装备：看增长区间、购买功能和关键装备前后的机会。没有同版本/同位置基准时不宣称“低于正常水平”或最优完成时间。
- 职责：结合位置看输出、先手、保护、救人、清线等需要；低经济辅助不因此等于失败，治疗总量也不能证明救人时机正确。
- 团队方向：最多挑几个值得追问的经济/经验节点；曲线反转是观察，不能称为一场已发生的团战或推塔。

先讲最重要且证据足的发现，并指出一项有效选择（确有依据时）。给少量优先改法及生效条件。用户要求详细时再分阶段展开、比较备选方案；其后追问围绕原目标继续，不重问比赛号。
