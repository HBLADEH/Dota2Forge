# 职责、团队与目标

team主题可读取双方匿名结算和lineup；区别核心输出、先手、反手、保护、推进等职责。只凭KDA、IMP、伤害或治疗总量不能分配输局责任：输出受时长和阵容影响，辅助经济不应按核心标准评判。

先陈述曲线能证明的走向，再讨论条件性的行动选择。天辉净资产或经验优势在某时刻反转，不证明那里发生了团战、有人没参团、漏放技能或某方拿下肉山。当前availability将死亡/团战/目标/视野事件标为not_integrated，即使OpenDota原接口可能有事件，也不能声称本工具已经接入。

结合阵容提出可执行的下一局方案：开团前选需要限制与需要保护的对象，围绕已完成关键装和兵线安排目标，胜利后考虑塔、肉山、视野或安全资源。目标和兵线如无本场事件，只作为条件建议，不写成对过去过程的还原。

视野建议先说信息需求与服务的下一步行动，不背可能过期的精确坐标。没有位置与插眼记录，不评价某只眼是否正确或谁该为被抓负责。缺少团战事件时，说明复核需要的时间段与事件，不以索要录像替代已有经济和出装分析。

回答“谁的问题”时给可改善因素和证据缺口，避免人身评价；当多个因素不能区分时明确无法归责。仍可提供一条职责相关的练习和验证方法，让结论有实际用途。
