# 双端原生 AI 复盘真实会话验收

Status: planned

## 目标
在后续获得部署/真实消息授权后，验收首版候选在 GsCore 与 AstrBot 正常聊天中的模型召回、连续历史与图片递送。离线实现与 SDK 隔离证据不替代本任务。

## 非目标
不在当前实施任务中部署、发布、修改真实配置或发送真实消息；不提交凭据与聊天原文，不新增录像事件能力。

## 验收
- 两端各使用现有模型完成至少五轮：开始复盘、对线追问、出装比较、经济补图、图后继续；后续不重复比赛 ID，泛化追问仍可召回受限工具。
- 图与文字事实进入当前历史一次，图片只在需要时发送，宿主 persona 禁用与发送权限保持有效；模型/图/发送失败不盲重试。
- 验证 11 分钟证据刷新、绝对 2 小时失效、切换比赛/视角、群内他人、清空历史/同 ID 代际替换、改绑/解绑、停用/重载和资源排空。
- 人工评估来源引用、未知与推断、当时版本，不把终局补刀/购买记录解释成对线补刀/完整库存；不声称看到了尚未提供的死亡、视野、团战操作。
- 仅记录脱敏的宿主版本、模型类型、轮数、工具/图片数量、通过与失败原因；不保存真实聊天、用户/群身份或原始比赛响应。
