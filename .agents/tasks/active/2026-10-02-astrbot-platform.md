Status: in_progress

## 目标

## 验收
- [x] 核对固定 AstrBot 版本的插件发现、配置、事件、消息与生命周期 API。
- [x] 提供可安装的发现桥接、元数据、配置 Schema 和明确步骤；库导入无需宿主 SDK，无网络/文件写入/后台任务。
- [x] 可信事件构造四维身份；命令不接受目标平台身份，不导入 Dota2UID。

- [x] 图片使用宿主消息组件；渲染失败仅回退同次数据，发送失败不重发。
- [x] 初始化创建专用 SQLite/HTTP/Renderer；终止取消在途任务并关闭资源，可重复关闭，新实例不复用旧资源。

- [x] 在授权AstrBot4.28.2实例中验证真实发现/配置加载、冷启动、重载、terminate资源关闭与恢复ready。
- [x] 修复真实菜单的依赖重载类型冲突，用户复测确认收到图片。
- [x] 验证真实聊天的绑定、查询、分页/选择和图片可读性。
