# Core 最小业务闭环

Status: planned

## 目标
实现框架无关的账号绑定、玩家与最近比赛查询最小闭环，为 Dota2UID 首个命令提供可测试的公开用例。

## 非目标
完整 AI Agent、跨平台调度、部署整合、全部数据源覆盖。

## 验收
- 严格验证 SteamID32/64 与平台身份，SQLite 绑定仓库通过持久化及隔离测试。
- Provider 端口、归一化模型保留来源与时间；有效空结果、隐私、限流、超时分别表达。
- 先以离线 fixture 打通用例；实际 STRATZ schema 与授权方式核实后接入主数据源。
- 不依赖平台 SDK 运行；Core 业务覆盖率至少 80%，离线测试不依赖凭据。
- GsCore 接入前确认宿主版本、UID/存储契约和生命周期。
