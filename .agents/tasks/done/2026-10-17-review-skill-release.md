# 双端复盘 Skill 发版

Status: done

## 目标
用户明确授权分别整理并发布 GsCore / Dota2UID 和 AstrBot 插件，供稍后自行测试；撤销此前 AstrBot 暂不发版限制。

## 非目标
不替用户发送真实聊天，不修改正在运行的宿主、配置、绑定、订阅或模型；不把离线检查写成真实模型效果验收。

## 验收
- 核对远端主分支、既有测试分支和版本标签，保留工作区已有修改。
- 整理双端更新说明、升级边界、Skill 接入方式及真实未验证项。
- 源码统一离线检查及两端分发隔离安装通过；固定源码和分发提交。
- 分别更新分发仓库并新建对应版本 Release；附件、版本、仓库与 ZIP 摘要一致，旧版保留。
- 记录公开链接、更新步骤和建议测试入口。

## 影响模块与决策
双端适配器文档、源码与分发版本、发行附件；沿用既有复盘 Skill 和发布契约，不改变 Provider、存储或权限。
