# STRATZ攻略验证与OpenDota英雄出装

Status: done

## 目标
显式使用本机已有STRATZ配置验证攻略schema及两个英雄/位置的小样本；实现双端do[英雄名或简写]出装，输出OpenDota职业比赛分阶段物品购买统计。

## 非目标
不查询真实玩家、不发布/重启宿主/发聊天消息；不将统计称为完整攻略/胜率/最优顺序。STRATZ本轮仅验证，不注册未经确认的攻略命令；不缓存或静默换源。

## 验收
- STRATZ可获取性、schema/查询、出装/加点/天赋/补丁/样本/时间可用程度和缺失明确留证；凭据/原始账号响应不落盘。
- Core统一英雄名称/别名解析；歧义返回候选，未知不猜，提供独立出装端口/不可变结果/来源时间。
- OpenDota四阶段计数严格校验；0、空、缺失与失败区别保留；两端动态命令与帮助/菜单可用，取消/关闭保真。
- 普通测试禁网；统一离线检查、构建及双端消费/图片文本回退验证通过。
