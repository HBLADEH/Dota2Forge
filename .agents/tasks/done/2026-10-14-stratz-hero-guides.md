# STRATZ 英雄数据攻略与比赛样例

Status: done

## 目标
实现[规划](../../../Dota2Forge_STRATZ_FEATURE_PLAN.md)的 do英雄攻略/do攻略 与 do攻略样例；默认两页、详细最多四页，展示统计构筑与截图补充的单场加点网格、分类事件时间线和来源装备快照。

## 非目标
不将热门统计称最优，不拼未经验证的加点顺序，不静默用OpenDota出装替代，不推断命石/教学文字，不发布或部署。

## 验收
- 消费[口径核查](2026-10-14-stratz-data-readiness.md)，聚合与单场模型/来源/分母分开；week不能伪装精确当前补丁。
- 复用HeroCatalog，位置和歧义明确选择，省略位置不猜辅助/核心；未知英雄/物品/技能保留ID。
- 购买用目标matchPlayer.stats.itemPurchases，保留重复、组件、负数赛前时刻；时间语义不猜成合成完成。
- 样例技能顺序与天赋按真实返回展示；聚合每级热门选择不拼成合法路线，缺完整样例时说明缺口。
- 核实升级记录level语义后，按可用等级绘制1–25级分区网格，26–30级/特殊技能可扩展；缺英雄等级关联时只列真实时间/顺序，不补空格或猜加点。
- 单场摘要含实际位置/阵营、版本、KDA/IMP/时长；购买按已核实物品类别分组，未知保留未分类，中立获得另查且不由最终槽反推时刻。原附件身份/真实统计不作fixture。
- 装备快照复用来源六装备/三背包/中立槽，仅结束状态/语义核实时称最终；不由购买列表模拟任意时间库存，不在静态图片画可操作滑块。
- 出门/鞋/天赋/物品/技能各自显示可验证统计，错误不作为空；模块单独失败附来源错误，null/空/0区分。
- 默认2页/详细最多4页，780px与2MiB上限、同次文字回退；可用本地资源、缺图/长名/未知技能仍可读。
- Core/Renderer/双端运行时及发现桥接消费相同契约，原do出装保持原来源/指令。
