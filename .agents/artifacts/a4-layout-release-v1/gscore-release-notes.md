# Dota2UID 0.1.0a4

这次主要让出装和比赛图片更好读：

- 常见长装备名使用 A杖、臂章、祭品等简称，图片格子增加留白，文字回复保留完整名称。
- 出装展示各阶段装备图、名称和购买次数；比赛展示英雄、六件装备及等级、补刀、经济、伤害和治疗量。
- 比赛按阵营分页，十人通常为四张图。缺失数据标为未知，不补造统计。

这是 M0 预览版。需要 Python 3.12+；请先关闭宿主，用它实际运行的 Python 执行插件里的 `install_runtime.py`，安装成功后重新启动。只在商店点击安装还不能直接使用。安装器校验运行包版本和 SHA256，并检查依赖冲突；更新时也要重新执行。

英雄/装备图片来自另行配置的本地素材包；没有素材仍可显示名称和占位。当前版本的真实聊天、新增字段在线查询、Linux 宿主及订阅实际推送尚未验收，订阅默认关闭。历史版本验证不代表本版已完成这些验收。
