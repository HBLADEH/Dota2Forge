# Dota2UID 0.1.0a14：订阅比赛详情卡

- 比赛订阅在图片模式发送比赛总览、天辉详情和夜魇详情，突出订阅玩家，并保留事件 ID、来源、抓取时间和有限观察提示。
- 复用完整比赛报告的十人指标与装备槽，缺失保留未知，表现候选明确为非官方 MVP；相同来源时间只显示一次。
- 全部卡片渲染后通过一次 `target_send` 提交；绘图失败回退同一报告的完整分段文字。发送失败或未知回执不自动补发文字。
- 与素材替换和插件关闭协调，停止时拒绝尚未提交的订阅发送。

随包运行组件：Dota2UID a14、Core a7、Renderer a7、Assets a1。Python 3.12+，HTTPX/Pillow 沿用宿主兼容约束。

更新前备份 `data/Dota2UID`，先执行 `do停用`；更新后受控重载或冷启动，并通过 `do核心状态` 确认运行代际。旧 a6–a9 首次升级须完整冷启动；不兼容变更或排空失败仍要求冷启动。配置、绑定、订阅与既有素材保留。

M0 预发行；订阅默认关闭。2054 项禁网测试、五包构建及隔离安装通过；真实宿主主动订阅发送与客户端图片压缩另行验收。商店收录状态单独确认。
