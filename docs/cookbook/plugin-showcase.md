## 拍摄与脱敏

1. 原始截图留在本机；仓库只接收最终脱敏图片，不提交真实聊天记录或未脱敏数据。
2. 优先裁出本次命令和 Bot 返回。遮盖聊天昵称 / 头像、玩家昵称 / 头像、账号 ID、群号、会话标识、私人路径和全部 Token；比赛 ID 能关联账号，也应遮盖。命令中的 ID 同样处理。
3. 图内其他参赛者昵称、账号和头像也须处理；保留英雄、装备、统计、来源、时间及“不完整 / 未知 / 预估”说明。
4. 建议 PNG、宽至少 780px，原比例，不加滤镜。卡片勿裁掉脚注，长卡拆为可读图片；确认约 390px 手机宽下仍能阅读。
5. 配置图不截整份真实配置；使用字段局部画面并遮盖值，保留 namespace / reply_mode / illustration_path 等字段名。只编辑截图显示，不改变真实宿主配置。
6. 记录原宿主版本、插件 / 共享库版本、截图日期与测试范围；跨端复用仍标明原宿主。截图只证明该画面，不能推定其他端、权限或生命周期通过。
