# 正常对话复盘

以下为开发候选，尚未生产发布或真实聊天联调。使用宿主已经配置的AI；先启动一场复盘，再按平时方式追问，不用每条消息重复比赛ID。

```text
do复盘 <比赛ID> [英雄]
do复盘 最近
do复盘 第2场 斧王
do复盘 <比赛ID> [英雄] 报告
```

“最近”使用本人绑定的账号；“第N场”只来自本会话成功发送且仍有效的战绩列表。未指定英雄可用自己的绑定偏好或双方概览，英雄不存在/重复时要求核实，匿名不猜身份。

开始后可以继续：“为什么？”、“那这件呢？”、“经济曲线给我看一下”、“对线有哪些需要改进？”、“看完这张图还能改哪里？” 文字先回答当前重点，有必要时AI调用数据图工具；明确要求报告时可以完整展开。`do复盘 经济/装备/对线/团队`可在有效原生定位中切换主题。

群聊若宿主设置“仅@才回复”，每次追问也需@机器人，例如“@机器人 这把有什么问题？”或“@机器人 给我看看经济曲线”。do复盘建立比赛定位，不改变@触发策略；@后应取当前主题详细数据，不仅分析前轮短回复。

开始复盘需要比赛ID；定位有效时证据过期自动重新取证。活动30分钟、最长2小时；换会话、清空历史、改绑/解绑、停用或重载会清理，之后重新定位比赛。群里另一位用户不继承你的定位。图失败仍可文字交流，发送失败不自动重发。

如果宿主没有可用原生AI/模型，命令返回来源事实；带“报告”返回共享比赛数据报告。没有配置Token或数据源失败时明确显示原因，不编造比赛结论。本版有基础战绩、经济与购买观察，尚无死亡/团战/视野事件，AI只能把相关建议明确标为推测，不能声称看到录像操作。
