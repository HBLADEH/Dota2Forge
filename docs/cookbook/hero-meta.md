# 强势英雄与攻略指令

适用于Dota2UID a16／AstrBot alpha.14。两个适配器用相同Core业务和Forge卡片；配置Token的方法沿用既有安装指南，不在聊天中发送凭据。AstrBot按宿主配置加斜线或唤醒前缀。

```text
do强势
do强势 3号位 段位=传奇 7天
do强势 1号位 14天 胜率
do主宰攻略 1号位
do攻略 斧王 3号位 详细
do攻略样例 <比赛ID> 拉比克
```

强势默认每个位置2名；指定位置最多10名、每页5名。默认可靠度为Wilson95%下界，最低1000场；显示胜率、场次、版本、真实窗口与数据延迟。上游缺日不补零；没有可用样本时明确提示，不给“上分保证”。段位可用全部、未定级、先锋、卫士、中军、统帅、传奇、万古、超凡、冠绝。

攻略默认1号位，建议明确实际位置。默认最多2页，详细最多4页，缺失模块不发送空白长图；聚合统计与单场来源样例分别标记。如果提示“来源统计位置与所选位置不一致”，这些统计已停用，样例仍按实际位置校验。统计窗口尚未核实；加点序号不是英雄等级；购买记录保留赛前/重复/组件，无法由购买记录推断任意时刻库存。超过卡片上限显示总条数，AI攻略工具也有明示输出上限。

`doAM出装`与`do出装 <英雄>`仍是OpenDota职业购买热门统计，适用口径不同。见[契约](../subsystems/hero-features.md)、[攻略来源与实测](hero-guides.md)、[多轮复盘](native-review.md)。
