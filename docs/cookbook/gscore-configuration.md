# Dota2UID 后台配置

本页用于 **0.1.0a7**；旧 a6 仍读取 TOML，更新前不会出现这些参数。发行状态以 [Releases](https://github.com/HBLADEH/Dota2UID/releases)为准。配置使用 GsCore 现有后台，宿主源码无需修改。

## 设置与生效

1. 后台打开 **插件配置 → Dota2UID → 插件参数配置**。
2. 填写 STRATZ Token，确认部署 namespace；按需要调整回复、素材和订阅，点击 **确认修改**。
3. 用主人身份发送 `do停用`，确认关闭后点击 **重载当前插件**，或完整重启 GsCore。
4. 发送 `do核心状态`；合法且 Token 非空时业务应为 ready，空 Token 为 awaiting_config。实际查询仍取决于 Token 权限与 Provider 响应。

保存只更新下次启动使用的配置，正在运行的客户端和调度保留当前快照。更换随包运行库必须完整冷启动。原生批量保存逐项处理；非法字段会被拒绝，其他合法字段可能已保存，应检查显示值再重载。

## 参数

| 参数 | 用途与范围 |
| --- | --- |
| STRATZ Token | 密码输入；留空等待配置，不发送到聊天 |
| 部署 namespace | 小写字母开头，字母/数字/`_.-`，最多64字符；改变会切换身份分区，原绑定不会自动迁移 |
| 请求超时 | 大于0、最多60秒 |
| 回复模式 | image 或 text |
| 自定义素材路径 | 空值使用托管素材；相对路径基于 data/Dota2UID |
| 素材下载模式 | auto 首次后台准备；manual 主人显式准备；off 关闭托管下载 |
| 素材代理 | 空值直连；显式 HTTP/HTTPS 代理，仅用于素材下载 |
| 启用订阅 | 默认关闭；开启前确定推送归属 |
| 订阅检查间隔 | 60–86400秒 |
| 日报小时 | 0–23，固定北京时间 UTC+8 |
| 可信平台映射 | JSON 对象，例如 `{"onebot":"qq","qq":"qq","telegram":"telegram"}`；未知平台仍拒绝 |

Token 和代理字段使用宿主密码控件；已登录管理员 API 与原生配置文件可读取原值，控件隐藏不代表加密存储。不要提交或上传配置文件。

插件在原生参数读取前安装专用隐私保护，仅让 Dota2UID 配置接口绕过宿主 HTTP 正文追踪，避免 Token 被响应归档记录；鉴权、正常 JSON 响应和其他接口追踪保留。停用业务后该保护继续存在。

## 旧配置与修复

首次没有 `data/Dota2UID/config.json` 时，从原 `config.toml` 导入参数；原文件与数据库保留。之后后台 JSON 是唯一来源，修改旧 TOML 不生效，清空后台 Token 也不会使用旧 Token。无旧文件时使用安全默认值，订阅关闭、Token 留空。

无法解析、类型不符或未知字段的旧文件/后台文件会明确失败并保留原件；不要通过删除配置或数据库绕过错误。停用并备份专用数据后修复文件，再重载。合法但越界、错误代理等业务配置也会阻止启动，不会伪装为未填 Token。

回退到 a6 时，它仍读取保留的 TOML；先核对其中凭据与参数是否符合回退需求，再按[随包安装指南](gscore-bundled-install.md)恢复兼容分发和数据。
