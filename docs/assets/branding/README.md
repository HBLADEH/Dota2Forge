# Dota2Forge 插件图标

[juggernaut-icon-v1.png](juggernaut-icon-v1.png)为 GsCore / AstrBot 共用的主宰同人图标；生成于 2026-10-05，使用内置 image_gen，未使用 CLI/API 回退。工具未返回具体模型名。

设计采用 Q 版大头上半身、象牙色红纹面具、红色围巾、武士刀、白色圆徽章与红色外圈；圈外透明，无字标。方形 PNG 1254×1254，保留原始生成 alpha，未改图或缩放。README 显示为 256px，发行产物原样复制为 `Dota2UID/ICON.png` 与 `astrbot_plugin_dota2forge/logo.png`。

完整[最终提示词](juggernaut-icon-v1.prompt.txt)留存。参考 [NTEUID](https://github.com/tyql688/NTEUID) 的 Q 版圆形图标呈现方式，重新生成主宰角色；没有把其图像作为编辑输入，也未将参考美术纳入发行。README 结构参考 [GenshinUID](https://github.com/KimigaiiWuyi/GenshinUID)。

这是非官方同人插画；Dota 2、主宰及相关角色权利属于 Valve。代码的 MIT 许可不改变这些既有权利。插件标识与本地 Valve 卡片素材相互独立，不要求启用 illustration_path 才能显示插件图标。

维护新版本时保留现有图标，使用新文件名并同步发行生成器引用。功能展示截图另见[清单](../../cookbook/plugin-showcase.md)，当前图标不作为真实功能截图或宿主验收证据。
